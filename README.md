# Stralarp

GPS route simulator and `.gpx` creator/editor for Android.

- Kotlin + Jetpack Compose + Material 3 (dark athletic UI)
- osmdroid maps
- OSRM snap-to-road (free)
- Open-Meteo elevation
- Full GPX 1.1 import/export

## Build

Push to `main` or run the workflow manually in the Actions tab. The debug APK is uploaded as an artifact.
